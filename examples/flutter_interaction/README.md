# Flutter interaction sample

This small, self-contained example demonstrates one UI detail from ARK IA: a press animation that only runs when the action is available.

The example includes a widget test for the press, callback, reset, and unavailable-action behavior. It is intentionally limited to presentation code and does not contain app authentication, AI services, synchronization, server code, or release credentials.

Run it with Flutter from this directory:

```sh
flutter pub get
flutter test
```

For the wider project structure and development workflow, see [the technical overview](../../docs/DEVELOPMENT-PROCESS.md).
